# Beast Auto Reporter - История версий

## v4_stable_final - 25.01.2026

### Последние обновления:

#### 1. **Исправление PDF в отчётах** (коммит: c4aae8e)
- Проблема: PDF файлы (2.0/5.1) не добавлялись в DOCX как изображения
- Решение: Добавлена умная логика выбора PDF с приоритетом (cens → uncens → общий)
- Результат: PDF 2.0 и 5.1 теперь корректно встраиваются в конец документа

#### 2. **Исправление M&E TRUE PEAK** (коммит: e553501)
- Проблема: Ячейки TRUE PEAK в M&E таблице оставались пустыми
- Решение: Исправлена логика определения PDF ключей (pdf_20_c/pdf_51_c с приоритетом)
- Результат: TRUE PEAK для 2.0 ME и 5.1 ME теперь отображаются с цветовой индикацией

#### 3. **Знак "+" для положительных TRUE PEAK** (коммит: 8ea2ec3)
- Добавлен автоматический знак "+" для положительных значений TRUE PEAK
- Примеры: `-1.5 dBTP`, `0.0 dBTP`, `+1.2 dBTP`
- Применяется в основной таблице, M&E таблице и заключениях

#### 4. **Упрощённый формат видео** (коммит: 8fec3fe)
- Было: `MOV 25fps, TC: 01:00:00:00`
- Стало: `MOV 25fps`
- Убран таймкод из ячейки "Формат файла" для VIDEO

### Основные возможности v4_stable:

✅ **AI-генерация заключений** (Ollama llama3.2)
- Профессиональные технические и субъективные заключения
- Умная группировка проблем (щелчки + слюна)

- TRUE PEAK с знаком "+" для положительных значений
- Приоритет: cens → uncens → общий
- Встраивание PDF как изображений в отчёт

### Использование:

1. Запустить `Beast Auto Reporter.app`
2. Выбрать папку с файлами проекта
3. Выбрать тип отчёта (Основной/M&E)
4. Создать отчёт

### Требования к файлам:

- CSV маркер-лист
- Аудио: WAV (2.0/5.1, cens/uncens)
- Видео: MOV/MP4
- PDF: Youlean Loudness Meter отчёты (cens/uncens)
- Опционально: `Параметры.txt` (LUFS, TRUE PEAK, LRA)
