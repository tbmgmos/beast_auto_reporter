# 🎵 Beast Auto Reporter - Desktop Application

## 📋 Описание

Desktop приложение для автоматического создания отчетов по аудио контролю качества.

**Основные возможности:**
- 🖥️ Нативное desktop приложение (не веб-интерфейс)
- 📁 Выбор папки с файлами через GUI
- 🤖 Автоматическая генерация отчетов
- 📦 Создание выходной папки с результатами
- 🎯 Умное именование файлов

## 🔤 Логика именования

### Алгоритм:

1. **Берем имя аудио файла** (приоритет 2.0, затем 5.1)
2. **Удаляем служебные слова:**
   - `51`, `5.1`
   - `20`, `2.0`
   - `stereo`
   - `cense`, `censored`
   - `uncense`, `uncensored`
   - `audio`, `video`
   - `_c`, `_uc`

3. **Очищаем подчеркивания**
4. **Добавляем префикс:** `отчет_`
5. **Добавляем дату:** `_YYYY_MM_DD`
6. **Добавляем суффикс:** `_rus`

### Примеры:

| Входной файл | Базовое имя | Выходная папка |
|--------------|-------------|----------------|
| `audio_petr_2_s1_e2_20_cense.wav` | `petr_2_s1_e2` | `отчет_petr_2_s1_e2_2024_01_06_rus/` |
| `project_name_51_uncensored.wav` | `project_name` | `отчет_project_name_2024_01_06_rus/` |
| `show_s01_e05_stereo_c.wav` | `show_s01_e05` | `отчет_show_s01_e05_2024_01_06_rus/` |

- TRUE PEAK измерения
- Дополнительная техническая информация

## 🐛 Решение проблем

### Приложение не запускается:

```bash
# Проверьте зависимости
cd /Users/vladog/Desktop/Code_projects/Beast_Auto_Reporter
source venv/bin/activate
pip install -r requirements.txt
```

### Ошибка "Не найдены аудио файлы":
- Убедитесь, что в папке есть .wav, .mp3, .aiff или .flac файлы
- Проверьте, что в названии есть "2.0", "20", "5.1", "51" или "stereo"

### Ошибка при анализе:
- Проверьте, что аудио файлы не повреждены
- Убедитесь, что формат поддерживается

### .app не открывается:
```bash
# Дайте разрешение на запуск
chmod +x "dist/Beast Auto Reporter.app/Contents/MacOS/Beast Auto Reporter"

# Или разрешите в Системных настройках:
# Настройки > Конфиденциальность и безопасность
```

## 📊 Формат отчета

Отчет создается **точно** по шаблону `отчет_petr_2_s1_e2_2024_09_12_rus.docx`:

### Структура:

1. **Заголовок:**
   - Arial Unicode MS, 13pt, жирный
   - "MARKER LIST"

2. **Таблица (11 столбцов):**
   - Timecode In
   - Timecode Out
   - Description
   - 2.0 C
   - 2.0 UC
   - 5.1 C
   - 5.1 UC
   - БЛОКЕР
   - ТРЕБУЕТ ИСПРАВЛЕНИЯ
   - ТРЕБУЕТ КОММЕНТАРИЯ
   - КОММЕНТАРИИ

3. **Строки дефектов:**
   - Каждый дефект - отдельная строка
   - Автоматическая категоризация
   - Символы "*" для обозначений

## 🔧 Технические детали

### Используемые модули:
- `audio_analyzer.py` - анализ аудио
- `defect_detector.py` - детекция дефектов
- `template_report_generator.py` - генерация DOCX
- `pdf_extractor.py` - извлечение из PDF
- `timecode_analyzer.py` - анализ таймкодов

### Поддерживаемые форматы:
- **Аудио:** WAV, MP3, AIFF, FLAC
- **Видео:** MP4, MOV, MKV, AVI
- **Документы:** PDF, TXT
- **Выход:** DOCX, CSV
