========================================================
  ИНСТРУКЦИЯ ПО АКТИВАЦИИ AI-РЕЖИМА
  Beast Auto Reporter — Субъективное заключение
========================================================

AI-режим позволяет автоматически генерировать субъективное
заключение на основе маркер-листа (CSV). Без AI вместо
заключения вставляется заглушка [ЗАПОЛНИТЬ ВРУЧНУЮ].

Используется локальная AI-модель — все данные остаются
на вашем компьютере, ничего не отправляется в интернет.


--- ШАГ 1: УСТАНОВИТЬ OLLAMA ---

Ollama — это движок для запуска AI-моделей локально.

macOS:
    brew install ollama
    или скачать с https://ollama.com/download

Windows:
    Скачать установщик с https://ollama.com/download

Linux:
    curl -fsSL https://ollama.com/install.sh | sh


--- ШАГ 2: СКАЧАТЬ AI-МОДЕЛЬ ---

Откройте терминал (Terminal / Командная строка) и выполните:

    ollama pull gemma3:12b

Модель весит ~8 ГБ, скачивание займёт несколько минут.

Альтернативные модели (для слабых ПК):
    ollama pull qwen2.5         (~4 ГБ, хорош для русского)
    ollama pull mistral          (~4 ГБ, хороший баланс)
    ollama pull llama3.2         (~3 ГБ, быстрый, но хуже русский)


--- ШАГ 3: ЗАПУСТИТЬ OLLAMA ---

macOS / Linux:
    ollama serve

Windows:
    Ollama запускается автоматически после установки.
    Если нет — откройте приложение Ollama из меню Пуск.

Проверить, что Ollama работает:
    curl http://localhost:11434/api/tags
    (должен вернуть JSON со списком моделей)


--- ШАГ 4: УСТАНОВИТЬ PYTHON-БИБЛИОТЕКУ ---

Если вы запускаете из исходников (не из .app):

    pip install ollama==0.1.6


--- ШАГ 5: ВКЛЮЧИТЬ AI В ПРИЛОЖЕНИИ ---

Откройте файл главного приложения:
    beast_auto_reporter (v2 beta).py

Найдите строку (примерно строка 1974):
    self.conclusion_gen = ConclusionGenerator(use_llm=False)

Замените на:
    self.conclusion_gen = ConclusionGenerator(use_llm=True)

Сохраните файл.


--- ШАГ 6: ПРОВЕРИТЬ ---

1. Убедитесь, что Ollama запущена (ollama serve)
2. Запустите приложение
3. Загрузите CSV с маркерами
4. В субъективном заключении появится автоматически
   сгенерированный текст вместо [ЗАПОЛНИТЬ ВРУЧНУЮ]

Генерация занимает:
    С GPU (NVIDIA/Apple Silicon): ~3-10 секунд
    Без GPU (только CPU):        ~30-90 секунд


========================================================
  СИСТЕМНЫЕ ТРЕБОВАНИЯ
========================================================

Минимальные:
    ОЗУ:    12 ГБ (16 ГБ рекомендуется)
    Диск:   10 ГБ свободного места
    ОС:     macOS 12+ / Windows 10+ / Linux
    Python: 3.9+ (если из исходников)

GPU (опционально, ускоряет генерацию):
    macOS:  Apple Silicon (M1/M2/M3) — встроенная поддержка
    NVIDIA: CUDA-совместимая видеокарта (6+ ГБ VRAM)
    AMD:    ROCm (Linux)


========================================================
  НАСТРОЙКА
========================================================

Конфигурация AI находится в файле:
    config/settings.yaml

Раздел llm:
    model: "gemma3:12b"              # Какую модель использовать
    temperature: 0.15                # Стабильность текста (ниже = стабильнее)
    max_tokens: 1000                 # Макс. длина ответа
    language: "ru"                   # Язык (ru / en)
    ollama_host: "http://localhost:11434"  # Адрес Ollama
    timeout: 60                      # Таймаут в секундах

Если используете альтернативную модель — поменяйте model:
    model: "qwen2.5"
    model: "mistral"
    model: "llama3.2"


========================================================
  КАК ЭТО РАБОТАЕТ
========================================================

1. Вы загружаете CSV-файл с маркерами (проблемами)

2. Python группирует маркеры по типам:
   - Щёлкающие звуки / слюна
   - Шипение
   - Несинхронность реплик
   - Реверберация
   - Перегруз
   - Отсутствие звука
   - Маскировка нецензурной лексики
   - и другие...

3. AI-модель (gemma3:12b) пишет заключение-саммари:
   - Обобщённые проблемы (без таймкодов) — первыми
   - Частные проблемы (с таймкодами) — потом
   - Блокеры — последними

4. Python проверяет AI-заключение:
   - Правильное количество пунктов
   - Все ключевые таймкоды на месте
   - Нет выводов/рекомендаций

5. Если AI недоступна или заключение не прошло проверку —
   используется шаблонная Python-версия (без AI)


========================================================
  РЕШЕНИЕ ПРОБЛЕМ
========================================================

Ошибка "Ollama не найдена":
    Убедитесь, что Ollama запущена: ollama serve

Ошибка "Модель не найдена":
    Скачайте модель: ollama pull gemma3:12b

Генерация слишком долгая (>2 минут):
    Используйте модель полегче: ollama pull qwen2.5

Заключение некорректное:
    Будет автоматически заменено на Python-версию.
    Проверьте логи приложения для деталей.

Мало оперативной памяти:
    Используйте модель llama3.2 (~3 ГБ вместо ~8 ГБ)
    или увеличьте файл подкачки (swap).
