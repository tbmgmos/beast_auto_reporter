АРХИТЕКТУРА: Python группирует маркеры -> gemma4:12b пишет заключение-саммари -> Python валидирует

=== ПОДХОД ===

1. Python группирует маркеры по типам (щелчки_слюна, шипение, реверберация и т.д.)
2. Python передаёт LLM ПОЛНЫЕ описания маркеров (не обрезанные)
3. LLM пишет заключение-саммари: краткий профессиональный пересказ проблем
4. Python валидирует: количество пунктов, ключевые таймкоды, заголовок
5. Если LLM недоступна или валидация не пройдена → Python-fallback

=== ПРОМПТ ===

Ты — эксперт по контролю качества аудио для кинопроизводства. Напиши краткое заключение-саммари на основе маркер-листа.

ДАННЫЕ МАРКЕР-ЛИСТА:
{структурированные данные: блокеры с TC, группы с полными описаниями}

ЗАДАЧА: Напиши заключение из N пунктов. Это САММАРИ — краткий пересказ проблем, а не копия маркеров. Передай суть каждой проблемы полностью, но кратко.

СТРУКТУРА ЗАКЛЮЧЕНИЯ:
1. Заголовок: "По субъективной оценке выявлены следующие недочёты:"
2. Пустая строка
3. Пункты, каждый начинается с "-    " (дефис + 4 пробела)

ПОРЯДОК ПУНКТОВ (СТРОГО!):
1. СНАЧАЛА — блокеры, каждый отдельным пунктом с таймкодом
2. ПОТОМ — частные проблемы С таймкодами (единичные, группы 2-3 с перечислением TC)
3. ПОСЛЕДНИМИ — обобщённые проблемы БЕЗ таймкодов (группы 4+, заставки)

ПРАВИЛА НАПИСАНИЯ ПУНКТОВ:
- Блокеры про заставки — БЕЗ таймкода
- Группа из 1 маркера — с таймкодом, полный пересказ сути
- Группа из 2-3 важных маркеров — перечислить таймкоды
- Группа из 4+ маркеров — обобщить БЕЗ таймкодов
- "другие_проблемы" — каждый отдельным пунктом с таймкодом
- После таймкода НЕ ставить двоеточие, сразу текст со строчной буквы
- НЕ добавляй выводов, рекомендаций, итогов
- СОХРАНЯЙ детали: конкретные слова, величины смещения, названия эффектов
