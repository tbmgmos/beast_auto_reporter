========================================
🚀 БЫСТРОЕ ИСПРАВЛЕНИЕ
"Невозможно открыть программу"
========================================

ПРОБЛЕМА:
macOS блокирует приложение Beast Auto Reporter


✅ РЕШЕНИЕ 1: АВТОМАТИЧЕСКИЙ СКРИПТ (рекомендуется)
==========================================

1. Откройте Терминал:
   Finder → Программы → Утилиты → Терминал

2. Скопируйте и вставьте эту команду:
   
   cd ~/Desktop && ./ИСПРАВИТЬ_ЗАПУСК.sh

3. Нажмите Enter

4. Следуйте инструкциям на экране


✅ РЕШЕНИЕ 2: ВРУЧНУЮ (если скрипт не помог)
==========================================

1. Найдите приложение "Beast Auto Reporter.app"

2. ПРАВОЙ КНОПКОЙ МЫШИ на приложение

3. Выберите "Открыть" (НЕ "Открыть с помощью"!)

4. В появившемся окне нажмите "Открыть"

5. Готово! Теперь можно открывать обычным способом


✅ РЕШЕНИЕ 3: ЧЕРЕЗ ТЕРМИНАЛ
==========================================

Скопируйте команду (замените путь если нужно):

xattr -dr com.apple.quarantine ~/Desktop/"Beast Auto Reporter.app"


Для разных путей:

Desktop:
xattr -dr com.apple.quarantine ~/Desktop/"Beast Auto Reporter.app"

Downloads:
xattr -dr com.apple.quarantine ~/Downloads/"Beast Auto Reporter.app"

Applications:
xattr -dr com.apple.quarantine /Applications/"Beast Auto Reporter.app"


========================================
❓ ВСЕ РАВНО НЕ РАБОТАЕТ?
========================================

1. Проверьте версию macOS:
   Нужна macOS 11.0 или новее
   Проверить: Apple меню → Об этом Mac

2. Проверьте, что приложение полностью скачалось:
   Размер архива: ~178 MB или ~558 MB
   После распаковки: Beast Auto Reporter.app

3. Попробуйте скачать заново:
   Возможно архив поврежден

4. Установите FFmpeg (для работы с видео):
   brew install ffmpeg


========================================
📞 НУЖНА ПОМОЩЬ?
========================================

Отправьте разработчику:

1. Скриншот ошибки
2. Версию macOS (Apple меню → Об этом Mac)
3. Процессор (Intel или M1/M2/M3)
4. Вывод скрипта ИСПРАВИТЬ_ЗАПУСК.sh
