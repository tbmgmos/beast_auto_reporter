# Beast Auto Reporter v5.2 - Инструкция по установке и использованию

## 📦 Установка

### Системные требования:
- **macOS** 11.0 (Big Sur) или новее
- **Процессор:** Apple Silicon (M1/M2/M3) или Intel
- **Оперативная память:** минимум 4 GB RAM
- **Свободное место:** 500 MB

### Необходимые программы:
1. **FFmpeg** (для обработки аудио/видео)
   ```bash
   # Установка через Homebrew
   brew install ffmpeg
   ```

2. **Ollama** (опционально, для AI генерации заключений)
   ```bash
   # Скачать с https://ollama.ai
   # После установки:
   ollama pull llama3.2
   ```

### Установка приложения:

1. **Скачайте** архив `Beast_Auto_Reporter_v5.2_STABLE.zip`

2. **Распакуйте** архив (двойной клик)

3. **Переместите** `Beast Auto Reporter.app` в папку **Программы (Applications)**

4. **Первый запуск:**
   - Кликните правой кнопкой на приложение → **Открыть**
   - Подтвердите запуск (если macOS показывает предупреждение)
   - После первого запуска приложение можно запускать обычным способом

## 🚀 Использование

### Подготовка файлов:

Разместите в одной папке следующие файлы:

**Обязательные:**
- `имя_проекта.csv` - маркер-лист с проблемами

**Опциональные (в зависимости от типа отчета):**

**Для основного отчета:**
- `имя_20_cens.wav` - аудио 2.0 censored
- `имя_20_uncens.wav` - аудио 2.0 uncensored
- `имя_51_cens.wav` - аудио 5.1 censored
- `имя_51_uncens.wav` - аудио 5.1 uncensored
- `имя_20_cens.pdf` - Youlean отчет 2.0 censored
- `имя_20_uncens.pdf` - Youlean отчет 2.0 uncensored
- `имя_51_cens.pdf` - Youlean отчет 5.1 censored
- `имя_51_uncens.pdf` - Youlean отчет 5.1 uncensored
- `параметры.txt` - файл с целевыми параметрами

**Для M&E отчета:**
- `имя_20_cens.wav` - аудио 2.0 M&E
- `имя_51_cens.wav` - аудио 5.1 M&E
- `имя.mov` (или .mp4/.mkv) - видеофайл
- `имя_20_cens.pdf` - Youlean отчет 2.0
- `имя_51_cens.pdf` - Youlean отчет 5.1

### Формат файла параметры.txt:
```
LUFS 2.0: -16.0
LUFS 5.1: -18.0
TRUE PEAK: -2.0
LRA: 20.0
```

## 📋 Создание отчета:

1. **Выберите тип отчета:**
   - **Основной** - полный отчет с анализом проблем
   - **M&E** - упрощенный отчет для M&E материалов
   - **M&E (наши работы)** - для внутренних M&E с фиксированными заключениями
   - **TIFFLO (идеальный)** - для идеальных материалов

2. **Включите/выключите AI генерацию** (опционально, beta):
   - ☐ Выключено: субъективная оценка будет `[ЗАПОЛНИТЬ ВРУЧНУЮ]`
   - ☑ Включено: AI сгенерирует субъективную оценку через Ollama

3. **Нажмите "Выбрать папку"** и укажите папку с файлами

4. **Дождитесь завершения:**
   - Прогресс будет отображаться на экране
   - Папка с отчетом откроется автоматически

## 📊 Особенности работы:

### Автоматическое определение типов файлов:
- Приложение ищет в названиях файлов маркеры: `20`, `51`, `cens`, `uncens`
- Если маркеров нет - определяет тип по количеству каналов (ffprobe)

### Цветовая индикация в маркер-листе:
- **Коралловый фон** - новые маркеры (если в комментариях написано "НОВЫЙ МАРКЕР")
- **Красный текст** - ошибка в названии файла (21 вместо 20, 50 вместо 51)

### Цветовая индикация в технической таблице:
- 🟢 **Зеленый** (#00FA02) - параметры в норме
- 🔴 **Красный** (#E83121) - параметры выходят за допустимые значения
- 🟡 **Желтый** (#FBBA18) - предупреждение / неполные данные

### Заключения:
- **Техническая оценка:** генерируется автоматически по шаблонам
- **Субъективная оценка:**
  - Без AI: `[ЗАПОЛНИТЬ ВРУЧНУЮ]`
  - С AI: генерируется через Ollama с группировкой проблем

## ❗ Решение проблем:

### "Приложение не открывается"
```bash
# Снять карантин с приложения:
xattr -dr com.apple.quarantine "/Applications/Beast Auto Reporter.app"
```

### "ffprobe not found"
```bash
# Установить FFmpeg:
brew install ffmpeg

# Проверить установку:
which ffprobe
```

### "Ollama connection error" (при включенной AI генерации)
```bash
# Установить Ollama:
# Скачать с https://ollama.ai

# Запустить модель:
ollama pull llama3.2
ollama serve
```

### "Не извлекается информация из видео"
- Убедитесь, что ffprobe установлен: `which ffprobe`
- Проверьте формат видео (поддерживаются: .mov, .mp4, .mkv, .avi, .mxf, .m4v, .webm, .flv)
- Проверьте права доступа к файлу

### "Ошибка при обработке PDF"
- Убедитесь, что PDF файл создан в Youlean Loudness Meter
- Файл должен быть в формате PDF с текстовыми данными (не скан)

## 📝 Формат CSV файла (маркер-листа):

Обязательные колонки:
- **TC IN** - таймкод начала (формат: HH:MM:SS:FF)
- **ОПИСАНИЕ ПРОБЛЕМЫ** - описание проблемы
- **КОММЕНТАРИИ** - комментарии и статус ("НОВЫЙ МАРКЕР", "БЛОКЕР" и т.д.)

Пример:
```
TC IN,TC OUT,ДЛИНА,ОПИСАНИЕ ПРОБЛЕМЫ,КОММЕНТАРИИ
01:00:12:05,01:00:12:18,00:00:00:13,Щелкающий звук,
01:00:45:20,01:00:46:03,00:00:00:08,Неразборчивая реплика,БЛОКЕР
01:01:23:14,01:01:23:20,00:00:00:06,Шипение,НОВЫЙ МАРКЕР
```
