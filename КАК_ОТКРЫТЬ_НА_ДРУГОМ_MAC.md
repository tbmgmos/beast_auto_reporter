# Как открыть Beast Auto Reporter на другом Mac

## 🚨 Проблема: "Не удалось открыть программу"

macOS блокирует приложения, скачанные из интернета (карантин).

---

## ✅ Решение 1: Через контекстное меню (самый простой)

1. **Найдите приложение** `Beast Auto Reporter.app`
2. **Правой кнопкой мыши** (или Control+клик) → **Открыть**
3. В появившемся окне нажмите **"Открыть"**
4. После первого запуска приложение можно открывать обычным способом

---

## ✅ Решение 2: Через терминал (если решение 1 не помогло)

### Скопируйте и выполните команду:

```bash
xattr -dr com.apple.quarantine "/Applications/Beast Auto Reporter.app"
```

### Пошагово:

1. **Откройте Терминал** (Finder → Программы → Утилиты → Терминал)

2. **Скопируйте команду выше**

3. **Вставьте в терминал** и нажмите Enter

4. **Запустите приложение** обычным способом

---

## ✅ Решение 3: Если приложение в другой папке

Если приложение НЕ в папке `/Applications/`, измените путь:

```bash
# Если на Desktop:
xattr -dr com.apple.quarantine ~/Desktop/"Beast Auto Reporter.app"

# Если в Downloads:
xattr -dr com.apple.quarantine ~/Downloads/"Beast Auto Reporter.app"

# Или перетащите файл в терминал после команды:
xattr -dr com.apple.quarantine 
```
_(после последней команды перетащите файл .app в окно терминала и нажмите Enter)_

---

## 📋 Проверка успешности

После выполнения команды вы должны увидеть:
- **Ничего** (команда выполнилась без ошибок) ✅
- Или **"No such file or directory"** ❌ (неправильный путь)

Если путь неправильный - проверьте, где находится файл, и измените команду.

---

## 🔒 Почему это безопасно?

`xattr -dr com.apple.quarantine` - это стандартная команда macOS, которая:
- Снимает флаг "карантина" с файла
- Не изменяет само приложение
- Не отключает другую защиту macOS
- Используется разработчиками для тестирования

---

## ❓ Если все равно не работает

### Проверьте системные требования:

- **macOS:** 11.0 (Big Sur) или новее
- **Процессор:** Apple Silicon (M1/M2/M3) или Intel
- **FFmpeg:** Должен быть установлен (`brew install ffmpeg`)

### Запустите диагностику:

```bash
cd ~/Desktop
./Beast_Auto_Reporter_ДИАГНОСТИКА.sh
```

### Попробуйте запустить из терминала:

```bash
open "/Applications/Beast Auto Reporter.app"
```

Если появятся ошибки - они покажут причину проблемы.
