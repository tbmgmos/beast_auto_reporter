# Beast Auto Reporter - План разработки

## 🎯 Цель проекта
Создать локальное приложение для автоматической генерации отчетов о контроле качества аудио для видеоконтента.

## 📊 Архитектура системы

```
┌─────────────────────────────────────────────┐
│           Web UI (Frontend)                 │
│     Streamlit / Gradio / Flask              │
└──────────────────┬──────────────────────────┘
                   │
┌──────────────────▼──────────────────────────┐
│         Backend (Python)                    │
│  ┌──────────────────────────────────────┐  │
│  │  1. Audio Analyzer                   │  │
│  │     - LUFS/TRUE PEAK/LRA измерения   │  │
│  │     - pyloudnorm, librosa            │  │
│  ├──────────────────────────────────────┤  │
│  │  2. Defect Detector                  │  │
│  │     - Клики, шипение, перегруз       │  │
│  │     - librosa, scipy, pydub          │  │
│  ├──────────────────────────────────────┤  │
│  │  3. LLM Integration                  │  │
│  │     - Ollama (llama3, mistral)       │  │
│  │     - LangChain для промптов         │  │
│  ├──────────────────────────────────────┤  │
│  │  4. Report Generator                 │  │
│  │     - CSV: pandas                    │  │
│  │     - PDF: reportlab/matplotlib      │  │
│  │     - DOCX: python-docx              │  │
│  └──────────────────────────────────────┘  │
└─────────────────────────────────────────────┘
```

## 🛠️ Технологический стек

### Backend
- **Python 3.10+**
- **Анализ аудио:**
  - `pyloudnorm` - LUFS/LRA измерения
  - `librosa` - анализ аудио
  - `scipy` - обработка сигналов
  - `pydub` - работа с аудиофайлами
  - `ffmpeg-python` - конвертация форматов

- **LLM (локально):**
  - `ollama` - запуск локальных LLM
  - `langchain` - работа с промптами
  - Модели: llama3.2, mistral, qwen2.5

- **Генерация отчетов:**
  - `pandas` - CSV
  - `matplotlib` + `reportlab` - PDF с графиками
  - `python-docx` - DOCX документы

### Frontend
- **Streamlit** (рекомендуется) или **Gradio**
  - Простой и быстрый UI
  - Drag-and-drop для файлов
  - Прогресс-бары
  - Preview результатов

## 🎨 UI концепция

### Главный экран:
1. **Upload Section**
   - Аудио 2.0 (drag & drop)
   - Аудио 5.1 (drag & drop)
   - Видео (опционально, для таймкодов)

2. **Settings Panel**
   - Target LUFS: -23 ±0.5
   - TRUE PEAK: -2.0 dBTP
   - LRA: 18 LU
   - Язык отчета: RU/EN

3. **Analysis Progress**
   - Прогресс-бар
   - Текущая операция
   - Найденные дефекты (счетчик)

4. **Results Preview**
   - Таблица дефектов
   - Графики LUFS
   - Сгенерированное заключение

5. **Export**
   - Скачать CSV
   - Скачать PDF
   - Скачать DOCX
   - Скачать все (ZIP)

## 🔍 Типы дефектов для детекции

### Критичные (БЛОКЕРЫ):
- Отсутствие звука
- Перепутанные каналы 5.1
- Критический перегруз (>-1 dBTP)

### Требует исправления:
- Клики и треск
- Высокочастотное шипение
- Перегруз/пережатый звук
- Сильные отклонения LUFS

### Требует комментария:
- Слабые клики
- Несинхронность
- Склейки звука
- Слюна на репликах

## 📊 Метрики качества

- **LUFS**: -23 ±0.5 (стандарт EBU R128)
- **TRUE PEAK**: -2.0 dBTP (запас для кодирования)
- **LRA**: до 18 LU (динамический диапазон)
- **Формат**: 48kHz 24bit PCM

## 🔄 Workflow

```
1. Загрузка файлов
   ↓
2. Валидация (формат, битрейт, каналы)
   ↓
3. Анализ параметров (LUFS, TP, LRA)
   ↓
4. Детекция дефектов
   ↓
5. Генерация заключения (LLM)
   ↓
6. Создание отчетов (CSV, PDF, DOCX)
   ↓
7. Экспорт и скачивание
```
