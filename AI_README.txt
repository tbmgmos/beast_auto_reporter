========================================================
  Beast Auto Reporter — Активация AI режима
========================================================

AI режим использует локальную LLM модель через Ollama
для автоматической генерации заключений в отчётах.

--------------------------------------------------------
  Шаг 1: Установка Ollama
--------------------------------------------------------

1. Скачайте Ollama с официального сайта:
   https://ollama.com/download

2. Установите приложение (перетащите в /Applications)

3. Запустите Ollama (появится иконка в меню-баре)

--------------------------------------------------------
  Шаг 2: Загрузка модели
--------------------------------------------------------

Откройте Терминал и выполните:

   ollama pull gemma3:12b

Это рекомендуемая модель (требуется ~8 GB RAM).

Альтернативные модели:
   ollama pull llama3.2        (легче, ~4 GB RAM)
   ollama pull mistral          (~5 GB RAM)
   ollama pull qwen2.5          (~5 GB RAM)

--------------------------------------------------------
  Шаг 3: Включение AI в приложении
--------------------------------------------------------

1. Запустите Beast Auto Reporter
2. Поставьте галочку "AI" в интерфейсе приложения
3. AI будет автоматически генерировать заключения

--------------------------------------------------------
  Важно
--------------------------------------------------------

- Ollama должна быть запущена ДО начала генерации отчёта
- При первом запуске модель загружается в память (10-30 сек)
- AI работает полностью локально, данные не отправляются
  в интернет
- Для смены модели отредактируйте config/settings.yaml
  (параметр llm.model)

--------------------------------------------------------
  Устранение проблем
--------------------------------------------------------

"Ollama недоступна":
   - Проверьте, что Ollama запущена (иконка в меню-баре)
   - В Терминале: ollama list (должен показать модели)

"Модель не найдена":
   - Выполните: ollama pull gemma3:12b

Медленная генерация:
   - Попробуйте модель полегче: ollama pull llama3.2
   - Измените модель в config/settings.yaml
