## 📁 Структура входных данных

### Обязательные файлы:

```
ваша_папка/
├── audio_2.0_cens.wav          # Аудио 2.0 censored
├── audio_5.1_cens.wav          # Аудио 5.1 censored
└── Параметры.txt               # Технические требования
```

### Опциональные файлы:

```
ваша_папка/
├── audio_2.0_uncens.wav        # Uncensored версия
├── audio_5.1_uncens.wav        # Uncensored версия
├── video.mp4                   # Для таймкодов
├── report_2.0_cens.pdf         # Техническая информация
└── report_5.1_cens.pdf         # Техническая информация
```

### Формат Параметры.txt:

```
LUFS (LOUDNESS, интегральная громкость) = - 23 LUFS c допустимым отклонением +- 0.5 LUFS
TRUE PEAK  (dBTP, пиковые значения) = -2.0 dBTP 
LOUDNESS RANGE (LRA, диапазон громкости) = 18 LU
Формат файлова и порядок каналов - PCM 48kHz 24 bit L R и PCM 48kHz 24 bit L R C LFE Lb Rb
```

## 📊 Формат выходного отчета

Отчет генерируется **ТОЧНО** как ваш шаблон `отчет_petr_2_s1_e2_2024_09_12_rus.docx`:

### Структура:

```
┌───────────────────────────────────────────────────────────────────┐
│                         MARKER LIST                                │
├───────────┬─────────┬─────────────┬─────┬──────┬─────┬──────┬─────┤
│Timecode In│Out      │Description  │2.0 C│2.0 UC│5.1 C│5.1 UC│БЛОКЕР│...
├───────────┼─────────┼─────────────┼─────┼──────┼─────┼──────┼─────┤
│01:00:00:00│01:00:07 │В данном фра │  *  │      │  *  │      │  *  │...
│01:00:07:12│         │Звуковая дор │  *  │      │  *  │      │  *  │...
└───────────┴─────────┴─────────────┴─────┴──────┴─────┴──────┴─────┘
```

### Столбцы:

1. **Timecode In** - Начало дефекта (HH:MM:SS:FF)
2. **Timecode Out** - Конец дефекта
3. **Description** - Описание проблемы
4. **2.0 C** - Присутствует в стерео censored (*)
5. **2.0 UC** - Присутствует в стерео uncensored
6. **5.1 C** - Присутствует в 5.1 censored
7. **5.1 UC** - Присутствует в 5.1 uncensored
8. **БЛОКЕР** - Критичная проблема (*)
9. **ТРЕБУЕТ ИСПРАВЛЕНИЯ** - Нужно исправить (*)
10. **ТРЕБУЕТ КОММЕНТАРИЯ** - Нужен комментарий (*)
11. **КОММЕНТАРИИ** - Дополнительные комментарии

### Форматирование:

- Шрифт: **Arial Unicode MS**
- Размер: **13pt**
- Границы: **как в оригинале**
- Первая строка: **объединенные ячейки "MARKER LIST"**

### Пример 2: Программный API

```python
from src.audio_analyzer import AudioAnalyzer
from src.defect_detector import DefectDetector
from src.template_report_generator import TemplateReportGenerator
from src.timecode_analyzer import TimecodeAnalyzer

# Инициализация
config = load_config()
analyzer = AudioAnalyzer(config)
detector = DefectDetector(config)
generator = TemplateReportGenerator()
tc_analyzer = TimecodeAnalyzer()

# Анализ хронометража
timecode_info = tc_analyzer.analyze_all_files(
    audio_20="audio_2.0.wav",
    audio_51="audio_5.1.wav",
    video="video.mp4"
)

# Детекция дефектов
defects_20 = detector.analyze_file("audio_2.0.wav", "2.0")
defects_51 = detector.analyze_file("audio_5.1.wav", "5.1")
all_defects = defects_20 + defects_51

# Сортировка по таймкоду
all_defects.sort(key=lambda d: d.timecode_in)

# Генерация отчета
generator.create_report_from_template(
    defects=all_defects,
    output_path="отчет.docx",
    timecode_info=timecode_info
)
```

## 🔍 Типы обнаруживаемых дефектов

Система автоматически обнаруживает:

### Критичные (БЛОКЕРЫ):
- ❌ Отсутствие звука заставки
- ❌ Перепутанные каналы в 5.1
- ❌ Критический перегруз (>-1 dBTP)

### Требуют исправления:
- ⚠️ Клипинг и перегруз
- ⚠️ Высокочастотное шипение на репликах
- ⚠️ Клики и треск
- ⚠️ Несинхронность звука

### Требуют комментария:
- 💬 Слабые клики
- 💬 Склейки в звуке
- 💬 Слюна на репликах

## ⚙️ Настройка

### Изменение порогов детекции:

Отредактируйте `config/settings.yaml`:

```yaml
detection:
  click_threshold: 0.05        # Порог детекции кликов
  noise_threshold: -60         # Порог шипения (dB)
  clipping_threshold: -1.0     # Порог клипинга (dBTP)
  silence_threshold: -70       # Порог тишины (dB)
```

### Изменение целевых параметров:

```yaml
audio:
  target_lufs: -23.0           # Целевой LUFS
  lufs_tolerance: 0.5          # Допуск ±dB
  true_peak: -2.0              # Макс. TRUE PEAK
  lra_max: 18.0                # Макс. LRA
```

## 🛠️ Устранение проблем

### Проблема: "Ollama недоступна"

**Решение:**
```bash
# Установите Ollama
brew install ollama

# Запустите сервер
ollama serve &

# Скачайте модель
ollama pull llama3.2
```

### Проблема: "ffprobe not found"

**Решение:**
```bash
brew install ffmpeg
```

### Проблема: "Ошибка чтения PDF"

**Решение:**
- Убедитесь что PDF не защищен паролем
- Попробуйте пересохранить PDF

### Проблема: "Несовпадение хронометража"

**Решение:**
- Система автоматически обнаружит и добавит маркер
- Проверьте файлы вручную на соответствие

1. **Используйте качественные файлы**

2. **Загружайте все доступные файлы**
