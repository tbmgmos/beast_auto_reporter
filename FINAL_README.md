## 🎯 Что реализовано

### ✅ Desktop приложение (не веб!)

1. Извлекаем имя: petr_2_s1_e2_2.0_cens_2024_09_12_rus

## 🎯 Логика работы

### Входные файлы (что нужно в папке):

**Обязательно:**
- ✅ Хотя бы один аудио файл (2.0 или 5.1)

**Рекомендуется:**
- ✅ Аудио 2.0 Censored (например: `*_20_cens.wav` или `*_2.0_*.wav`)
- ✅ Аудио 5.1 Censored (например: `*_51_cens.wav` или `*_5.1_*.wav`)
- ✅ Параметры.txt (технические требования)
- ✅ Видео файл (для проверки синхронизации)
- ✅ PDF отчеты (для извлечения технических данных)

**Опционально:**
- Аудио Uncensored версии
- Дополнительные документы

### Поиск файлов (автоматически):

Приложение ищет в папке:

| Тип | Как определяется | Пример |
|-----|------------------|--------|
| **Аудио 2.0 C** | `2.0` или `20` + `cens` | `audio_20_cens.wav` |
| **Аудио 2.0 UC** | `2.0` + `uncens` | `audio_20_uncens.wav` |
| **Аудио 5.1 C** | `5.1` или `51` + `cens` | `audio_51_cens.wav` |
| **Аудио 5.1 UC** | `5.1` + `uncens` | `audio_51_uncens.wav` |
| **Видео** | `.mp4`, `.mov`, `.mkv` | `video.mp4` |
| **PDF** | `.pdf` + `2.0` или `5.1` | `report_20.pdf` |
| **Параметры** | `параметры` или `parametry` | `Параметры.txt` |

### Именование выходной папки:

**Формула:**
```
отчет_{базовое_имя}_{дата}_rus
```

**Базовое имя** извлекается из первого найденного аудио файла:
1. Берем имя файла без расширения
2. Удаляем служебные слова: `51`, `20`, `5.1`, `2.0`, `stereo`, `cense`, `uncense`, `audio`, `video`, `_c`, `_uc`
3. Убираем лишние подчеркивания
4. Добавляем текущую дату (`YYYY_MM_DD`)

**Примеры:**

| Входной файл | Базовое имя | Выходная папка |
|--------------|-------------|----------------|
| `petr_2_s1_e2_20_cens.wav` | `petr_2_s1_e2` | `отчет_petr_2_s1_e2_2026_01_06_rus/` |
| `show_name_51_uncens.wav` | `show_name` | `отчет_show_name_2026_01_06_rus/` |
| `project_stereo_c.wav` | `project` | `отчет_project_2026_01_06_rus/` |

### Что происходит внутри:

#### 1. Анализ хронометража
- Измеряет длительность аудио и видео файлов
- Извлекает стартовые таймкоды
- Сравнивает длительности (допуск 0.5 сек)

#### 2. Детекция дефектов
**Типы дефектов:**
- ❌ **Клипинг** - превышение пикового уровня
- ❌ **Клики/треск** - резкие импульсы
- ❌ **Hiss (шипение)** - высокочастотный шум
- ❌ **Отсутствие звука** - тишина более 2 секунд
- ❌ **Несоответствие LUFS** - отклонение от целевой громкости
- ❌ **Превышение TRUE PEAK** - пиковые значения выше нормы

**Категории серьезности:**
- 🔴 **БЛОКЕР** - критические проблемы (клипинг, отсутствие звука)
- 🟡 **ТРЕБУЕТ ИСПРАВЛЕНИЯ** - важные проблемы (клики, hiss)
- 🔵 **ТРЕБУЕТ КОММЕНТАРИЯ** - информация (LUFS, LRA)

#### 3. Генерация отчета
- **DOCX отчет** - точно по шаблону `отчет_petr_2_s1_e2_2024_09_12_rus.docx`
  - Таблица с 11 столбцами
  - Все дефекты с таймкодами
  - Правильное форматирование (Arial Unicode MS, 13pt)
  
- **CSV отчет** - для импорта в другие системы
  - Табличный формат
  - UTF-8 с BOM

#### 4. Копирование файлов
- ВСЕ файлы из входной папки копируются в выходную
- Сохраняются оригинальные имена
- Создаются новые файлы отчетов

## 🐛 Решение проблем

### Приложение не запускается

**Проблема:** macOS блокирует
**Решение:**
1. `Системные настройки` → `Конфиденциальность и безопасность`
2. Найдите сообщение о блокировке
3. Нажмите "Открыть в любом случае"

**Проблема:** Ошибка Python
**Решение:**
```bash
# Проверьте зависимости
cd "/Users/vladog/Desktop/Code_projects/Beast_Auto_Reporter"
source venv/bin/activate
pip install -r requirements.txt

# Запустите напрямую
python beast_app_qt.py
```

### Ошибка "Не найдены аудио файлы"

**Проблема:** Приложение не нашло аудио
**Причины:**
- В папке нет `.wav`, `.mp3`, `.aiff` или `.flac` файлов
- В названии нет маркеров `2.0`, `20`, `5.1`, `51`, `stereo`

**Решение:**
- Убедитесь, что файлы называются правильно
- Пример: `project_name_20_cens.wav` или `audio_51_censored.wav`

### Ошибка при анализе

**Проблема:** Приложение зависает или падает
**Причины:**
- Поврежденные аудио файлы
- Очень большие файлы (>2 ГБ)
- Неподдерживаемый формат

**Решение:**
- Проверьте, что файлы воспроизводятся
- Конвертируйте в WAV 48kHz 24bit
- Разделите большие файлы
