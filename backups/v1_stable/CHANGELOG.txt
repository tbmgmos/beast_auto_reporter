КЛЮЧЕВЫЕ ФУНКЦИИ:
-----------------
✅ Парсинг PDF (Youlean Loudness Meter)
   - LUFS (INTEGRATED): число перед "INTEGRATED"
   - TRUE PEAK: число перед "TRUE PEAK MAX"
   - LRA: число перед "LOUDNESS RANGE"
   - Учет переносов строк (\n)

✅ Автозаполнение технической таблицы
   - Название файлов (из аудио)
   - Хронометраж (H:MM:SS.mmm, точность как в Nuendo)
   - LOUDNESS, TRUE PEAK, LRA (из PDF)
   - Формат файла (48kHz, 24bit, channel order)

✅ Цветовая индикация
   - Зеленый: параметр в норме
   - Красный: превышение нормы
   - Оранжевый: нет данных для сравнения

✅ Дублирование данных
   - Если только 1 PDF → данные копируются для 2.0 и 5.1
   - Если 2 PDF → каждый для своей конфигурации

✅ Умное распознавание файлов
   - Аудио: _20.wav, _51.wav, _20_, _51_
   - PDF: _20.pdf, _51.pdf, _20., _51.
   - Приоритет 5.1 перед 2.0 (избежание конфликтов)

✅ Гибкость
   - Работает с неполным набором файлов
   - Предупреждения об отсутствующих файлах
   - Не копирует большие аудио/видео файлы в output

ТЕХНИЧЕСКИЕ ФАЙЛЫ:
-----------------
- beast_app_final.py: главное приложение (PyQt5 GUI)
- src/pdf_extractor.py: парсинг PDF
- src/exact_report_generator.py: генерация DOCX отчета
- src/technical_info_extractor.py: извлечение данных из аудио/видео
- src/csv_importer.py: импорт проблем из CSV
- src/conclusion_generator.py: генерация заключений

ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ:
--------------------
- Требуется виртуальное окружение (venv)
- Работает только на macOS (PyQt5)
- Поддержка только Youlean Loudness Meter PDF
