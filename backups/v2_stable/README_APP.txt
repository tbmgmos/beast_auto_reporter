===========================================
Beast Auto Reporter v2_stable
Standalone Application для macOS
===========================================

УСТАНОВКА:
----------
1. Распакуйте "Beast_Auto_Reporter_v2_stable.zip"
2. Перетащите "Beast Auto Reporter.app" в папку Applications
3. При первом запуске: 
   - Правый клик на приложении → Открыть
   - Подтвердите запуск (macOS может запросить разрешение)

ТРЕБОВАНИЯ:
-----------
✅ macOS 10.13 или новее
✅ ffprobe (для обработки видео)
   Установка: brew install ffmpeg
✅ Доступ к файловой системе

ИСПОЛЬЗОВАНИЕ:
--------------
1. Запустите приложение
2. Нажмите "Выбрать папку"
3. Выберите папку с файлами:
   - CSV (список проблем)
   - WAV/MP3 (аудио 2.0/5.1 cens/uncens)
   - MOV/MP4 (видео)
   - PDF (Youlean Loudness Meter 2.0/5.1)
   - Параметры.txt (опционально)
4. Нажмите "Создать отчет"
5. Отчет создается на рабочем столе

ПОДДЕРЖИВАЕМЫЕ ФОРМАТЫ:
----------------------
Аудио: .wav, .mp3, .aiff, .flac
Видео: .mp4, .mov, .mkv, .avi
PDF: Youlean Loudness Meter экспорты
CSV: таблица с проблемами (timecode, description)

ЦВЕТОВАЯ ИНДИКАЦИЯ:
------------------
🟢 Зеленый - параметр в норме
🔴 Красный - ошибка/превышение/некратность кадру
🟡 Желтый - неполные данные о формате
🟠 Оранжевый - предупреждение
