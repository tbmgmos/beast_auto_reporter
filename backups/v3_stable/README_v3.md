## 📋 Описание

Beast Auto Reporter v3_stable - приложение для автоматической генерации технических отчетов на основе:
- CSV файла с маркерами проблем
- Аудио файлов (2.0/5.1, cens/uncens)
- Видео файла
- PDF отчетов Youlean Loudness Meter (с поддержкой cens и uncens версий)
- Файла параметров.txt

---

## ✨ Ключевые особенности v3_stable

### 🆕 Новое в v3
- **Полная поддержка PDF для uncens файлов:** данные LOUDNESS, TRUE PEAK и LRA теперь корректно извлекаются и отображаются для всех версий (2.0 cens/uncens, 5.1 cens/uncens)
- **Улучшенное распознавание PDF:** автоматическая классификация по паттернам cens/uncens
- **Детальное логирование:** показывает найденные PDF файлы с их типом

### 🔄 Сохранено из v2
- **Выбор типа отчета:** Основной (с LOUDNESS, TRUE PEAK, LRA) или M&E (только TRUE PEAK)
- **Цветовая индикация параметров:**
  - 🟢 Зеленый - соответствие норме
  - 🔴 Красный - превышение / несоответствие
  - 🟡 Желтый - неполные данные формата
  - 🟠 Оранжевый - кратно кадру, но нет референса для сравнения
- **Автоопределение FPS:** 24/25 fps из видео файла через ffprobe
- **Проверка кратности кадру:** точность 1 мс
- **Интеллектуальные заключения:** технические и субъективные

### ✅ Сохранено из v1
- **Правильный парсинг PDF:** корректное извлечение LUFS, TRUE PEAK, LRA
- **Дублирование данных:** если есть только один PDF, данные копируются для обеих конфигураций
- **Точный хронометраж:** совпадение с Nuendo (использование round() для миллисекунд)
- **Умное распознавание файлов:** паттерны _20/_51, cens/uncens

## 📝 Использование

1. **Запустите приложение**
2. **Выберите тип отчета:**
   - 🎵 Основной (с LOUDNESS, TRUE PEAK, LRA)
   - 🎼 M&E (только TRUE PEAK)
3. **Выберите папку** с файлами:
   - CSV файл с маркерами (обязательно)
   - Аудио файлы: `*_20_c.wav`, `*_20_uc.wav`, `*_51_c.wav`, `*_51_uc.wav`
   - Видео файл: `*.mp4`, `*.mov`, etc.
   - PDF отчеты: `*_20_c.pdf`, `*_20_uc.pdf`, `*_51_c.pdf`, `*_51_uc.pdf`
   - Параметры.txt (опционально)
4. **Нажмите "СОЗДАТЬ ОТЧЕТ"**
5. **Готово!** Папка с отчетом откроется автоматически

Папка: `отчет_[название_файла]_[дата]_rus/`

Содержимое:
- `отчет_[название]_[дата]_rus.docx` - итоговый отчет

Структура DOCX:
1. **Страница 1:** Техническая таблица + заключения
2. **Страница 2:** Список маркеров + встроенные PDF

## 🔧 Технические детали

### Поддерживаемые форматы

**Аудио:** .wav, .mp3, .aiff, .flac  
**Видео:** .mp4, .mov, .mkv, .avi  
**PDF:** .pdf (Youlean Loudness Meter)  
**CSV:** .csv (маркеры проблем)

### Распознавание файлов

- **2.0 cens:** `*_20_c.*`, `*_20.*`, `*2.0*` (без uncens)
- **2.0 uncens:** `*_20_uc.*`, `*_20*uncens*`
- **5.1 cens:** `*_51_c.*`, `*_51.*`, `*5.1*` (без uncens)
- **5.1 uncens:** `*_51_uc.*`, `*_51*uncens*`

### Извлекаемые параметры

**Из аудио/видео:**
- Длительность (H:MM:SS.mmm)
- Sample Rate
- Bit Depth
- Channel Order
- FPS (для видео)
- Timecode (для видео)

**Из PDF:**
- INTEGRATED LOUDNESS (LUFS)
- TRUE PEAK MAX (dBTP)
- LOUDNESS RANGE (LU)

## 🎨 Цветовая индикация

### Хронометраж
- 🟢 **Зеленый:** Кратен кадру + совпадает с другими файлами
- 🔴 **Красный:** НЕ кратен кадру ИЛИ не совпадает с другими
- 🟠 **Оранжевый:** Кратен кадру, но нет референса для сравнения

### Формат файла
- 🟢 **Зеленый:** Полная информация о каналах (например, "L, R, C, LFE, Ls, Rs")
- 🟡 **Желтый:** Неполная информация (например, "6 channels")

### LOUDNESS / TRUE PEAK / LRA
- 🟢 **Зеленый:** В пределах нормы
- 🔴 **Красный:** Превышение допустимых значений
