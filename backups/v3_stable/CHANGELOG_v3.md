# Beast Auto Reporter v3_stable - Changelog

**Дата:** 11.01.2026  
**Версия:** v3_stable

## 🎯 Основные изменения

### ✨ Новые функции

1. **Поддержка PDF файлов для uncens версий**
   - Добавлены новые ключи для распознавания PDF файлов: `pdf_20_c`, `pdf_20_uc`, `pdf_51_c`, `pdf_51_uc`
   - Система теперь корректно распознает PDF файлы с паттернами `uncens` или `_uc`
   - Данные LOUDNESS, TRUE PEAK и LRA из uncens PDF файлов корректно отображаются в таблице

2. **Улучшенное распознавание файлов**
   - PDF файлы автоматически классифицируются как cens или uncens
   - Детальное логирование найденных PDF файлов с указанием их типа

3. **Обновленная структура таблицы**
   - Строки "2.0 uncens" и "5.1 uncens" теперь используют правильные PDF ключи
   - Все четыре строки аудио (2.0 cens/uncens, 5.1 cens/uncens) имеют полную поддержку PDF данных

### 🔧 Технические улучшения

- **beast_app_final.py:**
  - Расширен словарь `files` для поддержки отдельных PDF файлов cens/uncens
  - Улучшена логика распознавания PDF файлов с проверкой паттернов uncens
  - Добавлено извлечение технических параметров из всех четырех типов PDF
  - Обновлена проверка файлов для отслеживания всех PDF типов

- **exact_report_generator.py:**
  - Обновлены ключи PDF в таблице: `pdf_20_c`, `pdf_20_uc`, `pdf_51_c`, `pdf_51_uc`
  - Строки uncens теперь корректно заполняются данными из соответствующих PDF

### 📋 Сохраненные функции из v2_stable

- ✅ Выбор типа отчета (Основной / M&E) через радиокнопки
- ✅ Цветовая индикация параметров (красный/зеленый/желтый/оранжевый)
- ✅ Автоопределение FPS (24/25) из видео файла
- ✅ Проверка кратности длительности кадру (1 мс точность)
- ✅ Интеллектуальные заключения
- ✅ Дублирование PDF данных при отсутствии одного из файлов
- ✅ Корректный хронометраж (совпадение с Nuendo)
- ✅ Красивые таблицы с правильными границами

## 🐛 Исправленные проблемы

- **Критический баг:** Данные LOUDNESS, TRUE PEAK и LRA из uncens PDF файлов не отображались в таблице
- **Причина:** Строки uncens использовали `None` вместо правильных PDF ключей
- **Решение:** Добавлена полная поддержка отдельных PDF файлов для cens/uncens версий
