# CHANGELOG - Beast Auto Reporter v4_stable

## Версия: v4_stable (11.01.2026)

### 🎯 Основные изменения

#### 1. **Интеграция Ollama для генерации заключений** 🤖
- Добавлена поддержка локального LLM (Ollama с моделью llama3.2)
- Интеллектуальная генерация технических и субъективных заключений
- Автоматический fallback на шаблонный метод при недоступности Ollama
- Обучение на реальных примерах заключений

#### 2. **Новый формат заключений** 📝
- Использование дефисов `- ` вместо буллет-пойнтов `• `
- "Недочёты" вместо "недочеты" (с буквой ё)
- Формат: "По техническим характеристикам выявлены следующие недочёты:"
- Формат: "По субъективной оценке выявлены следующие недочёты:"

#### 3. **Умная группировка проблем** 🧠
- **Единичные проблемы** → с таймкодом: "На таймкоде 01:23:45:12 присутствует..."
- **2-3 проблемы** → перечисление: "На таймкодах 01:11:42:06 и 01:14:44:22..."
- **Повторяющиеся** → обобщение БЕЗ количества: "В фонограмме присутствуют..."
- **Щелчки + слюна** → объединение: "В фонограмме присутствуют посторонние щёлкающие звуки и яркие звуки слюны"

#### 4. **Визуальные индикаторы проблем** 🎨
- **Красная окраска текста** для файлов с ошибками в названии:
  - `50` вместо `51`
  - `21` вместо `20`
  - `5.0` вместо `5.1`
  - `2.1` вместо `2.0`
- Применяется в:
  - Технической таблице (колонка "НАЗВАНИЕ ФАЙЛОВ")
  - M&E таблице (колонка "НАЗВАНИЕ ФАЙЛОВ")
  - MARKER LIST (колонка "Description")

#### 5. **Коралловая окраска для новых маркеров** 🟠
- Строки с комментарием "НОВЫЙ МАРКЕР" выделяются коралловым фоном (#FF7F50)
- Применяется ко всей строке в MARKER LIST

#### 6. **Исправление даты в названии файлов** 📅
- Дата из `base_name` теперь неизменна (не дублируется)
- **Было:** `отчет_Project_2026_01_08_2026_01_11_rus.docx`
- **Стало:** `отчет_Project_2026_01_08_rus.docx`
- Актуальная дата показывается только в ячейке "ДАТА ОТЧЕТА:" внутри документа
- Поддержка любых форматов даты: `151202`, `15_12_02`, `2026_01_08`, `08.01.2026`

#### 7. **Улучшенное распознавание файлов** 🔍
- Файлы с некорректными названиями теперь распознаются и обрабатываются
- Логирование предупреждений: `⚠️ ОШИБКА В НАЗВАНИИ! Аудио 5.1: project_50_c.wav`
- Автоматическое присвоение к правильной категории (50 → 51, 21 → 20)

### 📊 Примеры заключений

#### Техническое заключение:
```
По техническим характеристикам выявлены следующие недочёты:
- Хронометраж видеофайла и аудиодорожек не совпадает
- Порядок каналов в 5.1 аудиодорожке некорректный
- Длительность файла 2.0 cens не кратна кадру (25 fps, длительность кадра 40.00 мс)
```

#### Субъективное заключение:
```
По субъективной оценке выявлены следующие недочёты:
- Отсутствует звук на заставках "Кинопоиск" и "Студия плюс"
- Звуковая дорожка начинается на таймкоде 01:00:07:12
- В фонограмме слишком высокое низкочастотное шипение на репликах актёров
- В фонограмме присутствуют посторонние щёлкающие звуки
- Некоторые реплики звучат прерывисто. Ощущение, что есть перегруз
- На таймкодах 01:11:42:06 и 01:14:44:22 реплики актёра выглядят неоднородно с изображением
```

### 🎓 Обучение Ollama

Ollama обучена генерировать заключения на основе реальных примеров:

**Промпты включают:**
- Точные инструкции по формату
- Примеры из реальных отчётов
- Правила группировки и обобщения
- Требования к стилю (простой, лаконичный, профессиональный)
- Низкая температура (0.2-0.3) для предсказуемости

**Fallback механизм:**
- При недоступности Ollama → автоматический переход на шаблонный метод
- Тот же формат и стиль заключений
- Без потери функциональности

### 🚀 Установка Ollama (опционально)

Для использования AI-генерации заключений:

1. Установите Ollama: `https://ollama.ai/`
2. Скачайте модель: `ollama pull llama3.2`
3. Запустите сервер: `ollama serve` (обычно запускается автоматически)

Если Ollama недоступна, приложение автоматически использует шаблонный метод.
