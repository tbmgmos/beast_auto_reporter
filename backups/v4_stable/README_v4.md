# Beast Auto Reporter v4_stable

## 📋 Описание

Стабильная версия v4 приложения для автоматической генерации профессиональных отчётов по контролю качества аудио/видео материалов с интеграцией AI (Ollama) для интеллектуальной генерации заключений.

**Дата релиза:** 11.01.2026

## 🎯 Новое в v4_stable

### 🤖 AI-генерация заключений
- Интеграция локального LLM (Ollama) для профессиональных формулировок
- Обучение на реальных примерах отчётов
- Автоматический fallback на шаблоны при недоступности Ollama

### 📝 Улучшенные заключения
- Правильный формат: "По техническим характеристикам выявлены следующие недочёты:"
- Умная группировка: единичные с таймкодом, повторяющиеся обобщённо
- Дефисы `- ` вместо буллет-пойнтов `• `
- Естественные формулировки в стиле профессиональных отчётов

### 🎨 Визуальные индикаторы
- 🔴 Красная окраска файлов с ошибками в названии (50/21 вместо 51/20)
- 🟠 Коралловая окраска строк "НОВЫЙ МАРКЕР"

### 📅 Корректная работа с датами
- Универсальная поддержка любых форматов даты в названии
- Актуальная дата в документе, неизменная в названии файла

```bash
python beast_app_final.py
```

## 📊 Формат заключений

### Техническое заключение

**Если проблем нет:**
```
По техническим характеристикам нареканий не выявлено
```

**Если есть проблемы:**
```
По техническим характеристикам выявлены следующие недочёты:
- Хронометраж видеофайла и аудиодорожек не совпадает
- Порядок каналов в 5.1 аудиодорожке некорректный
- Интегральная громкость (LUFS) фонограммы 2.0 (-22.3 LUFS) отклоняется от номинального значения (-23.0 LUFS)
```

### Субъективное заключение

**Если проблем нет:**
```
По субъективной оценке нареканий не выявлено
```

**Если есть проблемы:**
```
По субъективной оценке выявлены следующие недочёты:
- Отсутствует звук на заставках "Кинопоиск" и "Студия плюс"
- Звуковая дорожка начинается на таймкоде 01:00:07:12
- В фонограмме слишком высокое низкочастотное шипение на репликах актёров
- В фонограмме присутствуют посторонние щёлкающие звуки и яркие звуки слюны
- На таймкодах 01:11:42:06 и 01:14:44:22 реплики актёра выглядят неоднородно с изображением
```

**Правила формулировок:**
- 1 проблема → с таймкодом
- 2-3 проблемы → перечисление таймкодов через "и"
- Много проблем → обобщение без количества

## 🔧 Технические детали

### Извлечение данных из PDF

Приложение использует два метода для извлечения LOUDNESS, TRUE PEAK, LRA из PDF Youlean:

1. **PyPDF2** - первичный метод
2. **PyMuPDF (fitz)** - резервный метод при ошибках

### Определение FPS

FPS определяется автоматически из видео файла через `ffprobe`:
- 24 fps → длительность кадра 41.67 мс
- 25 fps → длительность кадра 40.00 мс

### Проверка кратности кадру

Длительность каждого аудио файла проверяется на кратность кадру с точностью 1 мс.

### AI-генерация заключений

**Ollama (если доступна):**
- Модель: `llama3.2`
- Температура: 0.2-0.3 (высокая предсказуемость)
- Промпты обучены на реальных примерах
- Fallback на шаблоны при ошибках

**Шаблонный метод (fallback):**
- Группировка по ключевым словам
- Умная логика формулировок
- Тот же формат, что и Ollama

## 🐛 Устранение неполадок

### Ollama не работает

**Проблема:** Заключения генерируются шаблонным методом

**Решение:**
1. Проверьте, запущен ли Ollama: `ollama list`
2. Скачайте модель: `ollama pull llama3.2`
3. Запустите сервер: `ollama serve`

### Файлы не распознаются

**Проблема:** Некоторые файлы не попадают в отчёт

**Решение:**
- Проверьте названия файлов (должны содержать `_20_`, `_51_`, `_uc`, `_c`)
- Файлы с ошибками (`_50_`, `_21_`) теперь распознаются автоматически
- Проверьте логи в терминале для деталей

### PDF данные не извлекаются

**Проблема:** LOUDNESS, TRUE PEAK, LRA не отображаются

**Решение:**
- Убедитесь, что PDF создан через Youlean Loudness Meter
- Проверьте, что PDF содержит ключевые слова: "INTEGRATED", "TRUE PEAK MAX", "LOUDNESS RANGE"
- Приложение использует два метода извлечения (PyPDF2 и PyMuPDF)
