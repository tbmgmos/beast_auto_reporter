## ✨ Ключевые возможности v4_stable

### 1️⃣ AI-генерация заключений (Ollama)
- Использование llama3.2 для профессиональной генерации заключений
- Автоматический fallback на шаблоны при недоступности Ollama
- Обучение на реальных примерах заключений

### 2️⃣ Новый формат заключений
- Дефисы вместо буллет-пойнтов (-)
- "недочёты" с буквой ё
- Формат: "По... выявлены следующие недочёты:"
- Умная группировка проблем:
  - Единичные проблемы → с таймкодом
  - 2-3 проблемы → через "и"
  - Повторяющиеся → обобщённо БЕЗ количества

### 3️⃣ Цветовая индикация
- **Красная окраска**: файлы с ошибками в названии (50/21/5.0/2.1)
  - В технической таблице
  - В MARKER LIST
- **Коралловая окраска**: строки с "НОВЫЙ МАРКЕР"
- **Зелёный/Красный/Жёлтый**: индикация соответствия норме

### 4️⃣ Умное распознавание файлов
- Автоопределение типа аудио (2.0/5.1) через ffprobe
- Поддержка некорректных названий (50 вместо 51, 21 вместо 20)
- Автоматическая классификация cens/uncens для PDF

### 5️⃣ PDF файлы

- Корректное извлечение LOUDNESS, TRUE PEAK, LRA

### 6️⃣ Технические проверки

- Проверка кратности длительности кадру (точность 1 мс)

### 7️⃣ Прочее
