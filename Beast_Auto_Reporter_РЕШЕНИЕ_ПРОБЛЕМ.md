# Beast Auto Reporter - Решение проблем

## 🚨 Частые проблемы и решения

### 1️⃣ Проблема: Видео не отображается в таблице M&E

#### Симптомы:
- Строка VIDEO в таблице пустая
- Нет информации о формате и FPS
- Хронометраж видео отсутствует

#### Причина:
`ffprobe` (часть FFmpeg) не установлен или не найден в системе

#### ✅ Решение:

**Шаг 1: Проверьте установку FFmpeg**
```bash
# Откройте Терминал и выполните:
which ffprobe
```

Если вы видите путь (например, `/opt/homebrew/bin/ffprobe`) - FFmpeg установлен ✅  
Если видите `ffprobe not found` - нужно установить ❌

**Шаг 2: Установите FFmpeg через Homebrew**

**Для Apple Silicon (M1/M2/M3):**
```bash
# 1. Установите Homebrew (если еще не установлен):
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 2. Добавьте Homebrew в PATH:
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"

# 3. Установите FFmpeg:
brew install ffmpeg

# 4. Проверьте установку:
ffprobe -version
```

**Для Intel Mac:**
```bash
# 1. Установите Homebrew (если еще не установлен):
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 2. Установите FFmpeg:
brew install ffmpeg

# 3. Проверьте установку:
ffprobe -version
```

**Шаг 3: Перезапустите приложение**

После установки FFmpeg закройте и снова откройте Beast Auto Reporter.

### 2️⃣ Проблема: Маркер-лист не отображается или отображается некорректно

#### Симптомы:
- Таблица маркер-листа пустая
- Проблемы с кодировкой (кракозябры)
- Не все строки отображаются
- Ошибка при чтении CSV

#### Возможные причины и решения:

#### ✅ Решение 1: Проверьте формат CSV файла

**Требования к CSV файлу:**
- Кодировка: **UTF-8**
- Разделитель: **запятая (,)**
- Обязательные колонки:
  - `TC IN` - таймкод начала (формат: `HH:MM:SS:FF`)
  - `ОПИСАНИЕ ПРОБЛЕМЫ` - текст проблемы
  - `КОММЕНТАРИИ` - комментарии (может быть пустым)

**Пример правильного CSV:**
```csv
TC IN,TC OUT,ДЛИНА,ОПИСАНИЕ ПРОБЛЕМЫ,КОММЕНТАРИИ
01:00:12:05,01:00:12:18,00:00:00:13,Щелкающий звук,
01:00:45:20,01:00:46:03,00:00:00:08,Неразборчивая реплика,БЛОКЕР
01:01:23:14,01:01:23:20,00:00:00:06,Шипение,НОВЫЙ МАРКЕР
```

#### ✅ Решение 2: Переконвертируйте CSV в правильную кодировку

**Если используете Excel:**
1. Откройте CSV в Excel
2. Файл → Сохранить как...
3. Формат: **CSV UTF-8 (разделитель - запятая) (.csv)**
4. Сохраните

**Если используете Numbers (Mac):**
1. Откройте CSV в Numbers
2. Файл → Экспортировать → CSV...
3. Текстовая кодировка: **UTF-8**
4. Экспортировать

**Через терминал (для продвинутых):**
```bash
# Конвертация из Windows-1251 в UTF-8:
iconv -f CP1251 -t UTF-8 input.csv > output.csv

# Конвертация из Mac Roman в UTF-8:
iconv -f MACROMAN -t UTF-8 input.csv > output.csv
```

#### ✅ Решение 3: Проверьте названия колонок

Убедитесь, что первая строка CSV содержит правильные названия колонок:
- `TC IN` (обязательно)
- `ОПИСАНИЕ ПРОБЛЕМЫ` (обязательно)
- `КОММЕНТАРИИ` (обязательно, но может быть пустым)

Другие колонки (`TC OUT`, `ДЛИНА` и т.д.) опциональны.

### 3️⃣ Проблема: Названия файлов помечаются красным (ошибка)

#### Симптомы:
- Название аудиофайла красного цвета в таблице
- Предупреждение "ОШИБКА В НАЗВАНИИ"

#### Причина:
Неправильный формат названия файла (используется `21` вместо `20` или `50` вместо `51`)

#### ✅ Решение:

**Правильные названия:**
- ✅ `проект_20_cens.wav` - стерео 2.0 censored
- ✅ `проект_20_uncens.wav` - стерео 2.0 uncensored
- ✅ `проект_51_cens.wav` - surround 5.1 censored
- ✅ `проект_51_uncens.wav` - surround 5.1 uncensored

**Неправильные названия:**
- ❌ `проект_21_cens.wav` - должно быть `20`, а не `21`
- ❌ `проект_50_cens.wav` - должно быть `51`, а не `50`

**Переименуйте файлы:**
```bash
# Пример переименования в терминале:
mv проект_21_cens.wav проект_20_cens.wav
mv проект_50_cens.wav проект_51_cens.wav
```

### 4️⃣ Проблема: Приложение не открывается на другом Mac

#### Симптомы:
- Приложение не запускается
- Сообщение "Поврежденное приложение"
- macOS блокирует запуск

#### ✅ Решение:

**Метод 1: Через контекстное меню**
1. Правой кнопкой мыши на `Beast Auto Reporter.app`
2. Выбрать **Открыть**
3. Подтвердить открытие
4. После первого запуска можно открывать обычным способом

**Метод 2: Через терминал (если метод 1 не помог)**
```bash
# Снять карантин с приложения:
xattr -dr com.apple.quarantine "/Applications/Beast Auto Reporter.app"
```

### 5️⃣ Проблема: Ollama не работает (при включенной AI генерации)

#### Симптомы:
- Ошибка "Ollama connection error"
- AI генерация не работает
- Субъективная оценка не генерируется

#### ✅ Решение:

**Шаг 1: Установите Ollama**
1. Скачайте с https://ollama.ai
2. Установите приложение
3. Запустите Ollama

**Шаг 2: Загрузите модель**
```bash
ollama pull llama3.2
```

**Шаг 3: Запустите сервер**
```bash
ollama serve
```

**Альтернатива:**
Если AI не нужен, просто **отключите чекбокс "AI генерация"** в приложении.  
Субъективная оценка будет заполнена как `[ЗАПОЛНИТЬ ВРУЧНУЮ]`.
